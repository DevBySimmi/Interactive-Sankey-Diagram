# 🌊 Interactive Sankey Diagram

An interactive Sankey Diagram created using **Python** and **Plotly** to visualize the flow of data between different sources and targets.

## 📊 Project Overview

A Sankey Diagram represents the movement or distribution of data using connected flows. The width of each flow shows the relative quantity or value being transferred.

This project demonstrates data flow between:

- Source A
- Source B
- Source C
- Target A
- Target B
- Target C

## ✨ Features

- Interactive data visualization
- Clear source-to-target flow representation
- Colorful nodes
- Flow widths based on data values
- Hover information
- Easy-to-understand layout

## 🛠️ Technologies Used

- Python
- Plotly
